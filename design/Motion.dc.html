HOUSE RULES FOR MOTION

TRANSFORM + OPACITY ONLY

No layout-shifting animation; aim for 60 fps on mid-range Android.

REDUCED MOTION FIRST

Every effect has a calm fallback behind prefers-reduced-motion.

LAZY TOYS

Game, river toy and easter egg load only when reached or opened.

SKIPPABLE, ONCE

Intro plays once per session and never blocks the content or LCP.

TOUCH ≠ HOVER

Hover effects get a tap equivalent; nothing important hides behind hover.

BUILD WITH PRIMITIVES

CSS scroll-driven animations and the Motion library first; GSAP only if a scene needs it.
